# 환경영향평가 대기질 보고서 자동 작성 시스템

AERMOD 모델링 결과를 기반으로 AI가 환경영향평가서를 자동으로 작성하는 시스템입니다.

## 주요 기능

- **AERMOD 자동 실행**: project.inp 파일을 실행하여 대기질 모델링 수행
- **참조 자료 활용**:
  - `sample` 폴더의 PDF 보고서 양식 참조
  - `data` 폴더의 정온시설 위치 및 현황측정자료 활용
- **AI 보고서 작성**: Google Gemini AI를 활용한 전문 보고서 생성
- **다양한 출력 형식**: TXT, DOCX 형식 지원 (HWP는 DOCX에서 변환 가능)

## 폴더 구조

```
G:\eia\
├── t2.py                    # 메인 실행 파일
├── requirements.txt         # 필요한 패키지 목록
├── input/
│   ├── project.inp         # AERMOD 입력 파일
│   └── project.out         # AERMOD 출력 파일 (자동 생성)
├── output/
│   ├── 대기질_환경영향평가서.txt             # 생성된 보고서 (TXT)
│   └── 대기질_환경영향평가서_20260121.docx  # 생성된 보고서 (DOCX, 타임스탬프 포함)
├── sample/
│   ├── (남해-여수 환평 본안)09220 대기질.pdf
│   └── (하기지구 국가산단) 11212 대기질.pdf
├── data/
│   ├── 정온시설.xlsx        # 정온시설 위치 정보 (38개 시설)
│   ├── 현황측정자료.xlsx
│   └── references/          # 외부 전문자료 폴더 (선택사항)
│       ├── 논문1.pdf
│       ├── 연구보고서.txt
│       └── 참고문헌.pdf
└── engine/
    └── aermod.exe          # AERMOD 실행 파일
```

## 설치 방법

1. 필요한 패키지 설치:
```bash
pip install -r requirements.txt
```

2. 필요한 패키지:
   - `google-genai`: Google Gemini API 사용
   - `pandas`: Excel 파일 읽기
   - `openpyxl`: Excel 파일 처리
   - `PyPDF2`: PDF 파일 읽기
   - `python-docx`: DOCX 파일 생성

## 사용 방법

### 1. 프로그램 실행
```bash
python t2.py
```

### 2. 명령어 사용

프로그램 실행 후 다음 명령어를 입력할 수 있습니다:

- **1. 모델링**: AERMOD 시뮬레이션만 실행
- **2. 분석**: 기존 AERMOD 결과를 분석하여 TXT 보고서 작성
- **3. 전체**: 모델링 + 분석을 한번에 실행 (TXT)
- **4. DOCX**: DOCX 형식으로 보고서 작성
- **5. 종료**: 프로그램 종료

### 3. 워크플로우 예시

#### 첫 실행 시:
```
명령을 입력하세요: 3
```
→ AERMOD 모델링 실행 + 보고서 작성 (TXT)

#### DOCX 파일 생성:
```
명령을 입력하세요: 4
```
→ 기존 결과로 DOCX 보고서 생성

#### HWP 파일 필요 시:
1. DOCX 명령으로 파일 생성
2. 생성된 `대기질_환경영향평가서.docx`를 한글(HWP)에서 열기
3. `파일 > 다른 이름으로 저장 > HWP 형식` 선택

## 보고서 작성 원리

### 1. 참조 자료 로딩
- **샘플 보고서** (sample/*.pdf): 보고서 양식과 구성 참조
- **정온시설 위치** (data/정온시설.xlsx): 영향 예측 대상 시설 정보 (전체 38개 시설)
- **현황측정자료** (data/현황측정자료.xlsx): 현황과 예측결과 비교 분석
- **외부 전문자료** (data/references/): 논문, 보고서 등 선행연구 인용 (선택사항)

### 2. AERMOD 결과 분석
- project.out 파일의 모델링 결과 읽기
- 오염물질별 최대 착지농도 추출
- 발생 위치(좌표) 파악

### 3. AI 보고서 생성
Google Gemini AI가 다음 기준으로 보고서 작성:
- 샘플 보고서와 동일한 양식 사용
- 정온시설 정보 반영 (전체 38개 시설)
- 현황과 예측결과 비교·분석
- 환경기준 대비 평가 및 적부 판정
- 전문 문체("~함", "~임") 사용
- **선행연구 및 전문자료 인용**: 예측결과의 타당성 검증을 위한 논문/보고서 인용

### 4. 외부 전문자료 추가 방법 (선택사항)
보고서의 신뢰성을 높이기 위해 외부 전문자료를 추가할 수 있습니다:

1. `G:\eia\data\references` 폴더 생성
2. 관련 논문, 연구보고서, 정부 보고서 등을 폴더에 저장
   - 지원 형식: PDF, TXT, DOCX
   - 예: "환경부_대기질관리지침_2022.pdf", "도로변대기질영향연구_Kim2020.pdf"
3. 프로그램 실행 시 자동으로 로딩되어 보고서에 인용됨

**인용 예시:**
- "이는 Kim et al.(2020)의 연구에서 제시한 도로변 대기질 영향범위와 유사한 결과임"
- "환경부(2022) 대기질 관리지침에 따르면..."
- "국립환경과학원(2021)의 연구결과와 비교 시..."

## 주의사항

1. **API 키 관리**
   - 현재 코드에 API 키가 하드코딩되어 있습니다
   - 보안을 위해 환경변수 사용을 권장합니다

2. **API 할당량**
   - Google Gemini API 할당량 초과 시 자동으로 재시도합니다
   - 35초 대기 후 최대 3회까지 재시도

3. **파일 크기 제한**
   - PDF: 최대 50페이지
   - 텍스트 추출: 최대 30,000자
   - Excel 데이터: 최대 5,000자

4. **AERMOD 실행**
   - 실행 시간 제한: 5분
   - 입력 파일: `input/project.inp` 필수
   - 작업 디렉토리: 자동으로 input 폴더로 변경
